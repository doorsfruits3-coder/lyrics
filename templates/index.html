Cách 1: Lấy Token cực nhanh qua F12 Console (Khuyên dùng)

  1. Mở Discord trên trình duyệt web (hoặc ứng dụng Discord trên máy tính).
  2. Nhấn phím F12 (hoặc Ctrl + Shift + I) để mở Developer Tools.
  3. Chọn tab Console, dán đoạn mã sau và nhấn Enter:
(webpackChunkdiscord_app.push([[''],{},e=>{m=[];for(let c in e.c)m.push(e.c[c])}]),m).find(m=>m?.exports?.default?.getToken!==void 0).exports.default.getToken()

➡️ Dòng chữ trả về trong ngoặc kép chính là Token của bạn. Copy và dán vào ô trên!

Cách 2: Lấy từ Cookie / Network

Trong F12, mở tab Network, tải lại trang Discord, tìm request có tên messages hoặc @me, tìm phần Request Headers và copy giá trị của dòng Authorization: ... hoặc toàn bộ header.
